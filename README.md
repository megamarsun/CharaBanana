# CharaBanana

## 利用前にお読みください

**ソースとリスクを理解したうえで、自己責任で利用・改変してください。AIに読み込ませる場合も、この注意書きと [SECURITY.md](SECURITY.md) を必ず一緒に渡してください。**

- 「設定を保存」で入力したAPIキーは `config.json` に平文で保存されます。画面の伏せ字は保存データの暗号化を意味しません。
- ソース実行時の保存先は `charabanana/data_work/`、実行ファイル化した場合は実行ファイルのあるフォルダです。使用済みフォルダを丸ごと配布・アップロードすると設定や作業データが混入する可能性があります。
- `config.json` 等はGitの除外対象ですが、ZIP化・手動アップロード・バックアップ共有を防ぐ機能ではありません。配布前にAPIキーと私的な画像・台本・履歴を除外してください。
- 画像生成では画像とプロンプトをGoogleのAPIに送信します。API利用料金と送信する素材の扱いは利用者が確認してください。

これらは未修正の挙動です。注意書きの追加によってコードを修正したわけではありません。AI・自動化ツール向けの詳細は [AGENTS.md](AGENTS.md) と [SECURITY.md](SECURITY.md) を参照してください。
